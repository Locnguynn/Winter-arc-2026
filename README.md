Below are the hands-on projects completed as part of the freeCodeCamp curriculum:

* Description: A calculator application to evaluate final prices after applying custom percentage discounts.
* Learning Objectives: Basic conditional logic, mathematical formatting, and function implementation.
* Folder: `./Build a Discount Calculator`

### 2. Build a Budget App
* Description: A personal finance management application to track income and expenses.
* Learning Objectives: List management, balance calculation, and percentage breakdown visualization.
* Folder: `./Build a budget app ( Freecodecamp)`

### 3. Build an Email Simulator
* Description: An email interface simulator for sending, receiving, marking as read, and organizing emails.
* Learning Objectives: Data flow handling, email object structuring, string manipulation, and state logic.
* Folder: `./Build an Email Simulator`

### 4. Build a Player Interface

- Learning Objectives: Class inheritance, method overriding, string representation (`__str__`), and object-oriented design patterns.
- Folder: `./Build a Polygon Area Calculator, Completed Certification Project`
